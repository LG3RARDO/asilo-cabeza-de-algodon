# Sistema Web Asilo 

Sistema web para la gestión médica, administrativa y financiera del Asilo de Ancianos Nueva Vida.

## Tecnologías utilizadas
- **Frontend:** React.js (puerto 3000)
- **Backend:** Node.js + Express.js (puerto 4000)
- **Base de datos:** PostgreSQL
- **Microservicios:** Python + Flask (Docker)
- **Autenticación:** JWT

## Estructura del proyecto
- `asilo-login/` — Interfaz web en React
- `asilo_backend/` — API REST en Node.js
- `ms_notificaciones/` — Microservicio de notificaciones (puerto 5001)
- `ms_reportes/` — Microservicio de reportes (puerto 5002)

## Módulos del sistema
1. Gestión de pacientes
2. Solicitudes médicas
3. Citas médicas
4. Laboratorio
5. Farmacia
6. Finanzas
7. Reportes
8. Notificaciones
